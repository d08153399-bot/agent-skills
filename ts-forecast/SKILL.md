# Прогнозы временных рядов — универсальный инструмент

Zero-shot прогнозирование: модель **Chronos-Bolt** (Amazon, Apache-2.0, ~0.2B) сразу даёт прогноз по истории ряда — без обучения на ваших данных. Всё считается **локально на Mac** (данные никуда не уходят; интернет нужен только при первом скачивании весов). Скорость: загрузка модели ~1–2 с, прогноз 0,02–0,1 с. Стоимость — $0.

## Когда применять
- «спрогнозируй…», «прогноз на N дней/недель/месяцев», «каким будет…», «что будет с…» (спрос / цена / выпуск / трафик / выручка), «тренд», «сезонность», «временной ряд», forecast.
- Любые исследования (рынки, конкуренты, метрики, технологии, финансы) — везде, где есть упорядоченный ряд во времени.
- Типовая связка для исследований: `deep-analyst` (сбор данных) → `ts-forecast` (прогноз) → файл-отчёт.

## Запуск
```bash
bash <папка_скилла>/scripts/run.sh \
  --csv данные.xlsx [--sheet "Лист1"] --date-col "Дата" \
  --value-cols "Ряд1;Ряд2" --freq W --horizon 6 \
  --backtest 6 --floor 0 --out отчёт.xlsx --chart прогноз.png
```
Быстрый ряд без файла: `--inline "10,12,14,13,15,17" --freq D --horizon 5`.

Параметры:
- `--horizon` — горизонт в периодах частоты (обязателен).
- `--freq` — `D/W/M/Q/Y` (по умолчанию авто по датам); недели — бизнес-недели пн–вс.
- `--value-cols` — колонки значений через «;» (в названиях бывают запятые; без флага берутся все числовые).
- `--resample sum|mean` (по умолчанию sum), `--fill zero|interp|ffill` (обработка пропусков).
- `--backtest N` — проверить модель на последних N точках против наивного, MA и сезонного бейзлайнов (WAPE) — делать для важных решений.
- `--floor 0` — не показывать отрицательные значения (для счётчиков/объёмов).
- `--model` — id модели на HF (по умолчанию `amazon/chronos-bolt-base`).

## Выход
- **xlsx**: лист «Сводка»; листы по сериям (факт + прогноз: медиана и квантили p10…p90); лист «Метрики» при `--backtest`.
- **png**: история + прогноз + вилка p10–p90.
- Консоль: краткая сводка (последняя точка, суммы медианы и вилки, метрики).

## Правила и тонкости
1. **Всегда сообщай горизонт, частоту и вилку** — не только точечный прогноз.
2. **Прерывистые ряды** (производство/продажи не каждый день, много нулей): дневная гранулярность слабее — агрегируй к неделе/месяцу; медиана занижает объём — проверяй сумму и калибруй по истории.
3. **Модель — не оракул**: для важных решений запускай `--backtest` и сравнивай с бейзлайнами; если модель не лучше наивного — говори об этом честно.
4. Экзогенные события (промо, праздники, смена цен) модель явно не знает — оговаривай в выводах и корректируй ожидания вручную.
5. Очень длинные ряды (>2–4 тыс. точек): модель работает по последним точкам; для десятилетий — сначала агрегируй.
6. Объёмные результаты — в файлы (xlsx/png), в чат — краткое резюме (стандарт `data-hygiene`).
