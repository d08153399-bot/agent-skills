# agent-skills — открытые скиллы от команды AI-Dimon

Установка (Claude Code и 18+ агентов):
```bash
npx skills add d08153399-bot/agent-skills --skill red-prosecutor
npx skills add d08153399-bot/agent-skills --skill yt-factcheck
```

- **red-prosecutor** — adversarial-проверка итогового текста свежим контекстом перед выдачей: логика, противоречия, правовые уязвимости — то, что не ловит формальная проверка. Найдёт ошибку до клиента.
- **yt-factcheck** — проверка YouTube-ролика по первоисточникам: каждое утверждение размечается (факт / преувеличение / реклама / не подтверждено), вердикт опирается на первоисточник.
- **ts-forecast** — универсальный zero-shot прогноз временных рядов (Chronos-Bolt, Apache-2.0): csv/xlsx/числа, дни–годы, квантили p10–p90, автобэктест против наивных бейзлайнов. Локально, $0.

MIT. Каждый скилл проверяется детерминированным барьером (frontmatter, размер, инъекции, ссылки) перед публикацией.
