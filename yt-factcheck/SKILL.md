# YT-Фактчек

По ссылке на YouTube-ролик строит таблицу вердиктов по каждому проверяемому утверждению (со ссылкой на первоисточник) и отдельно вскрывает скрытую рекламу.

## Когда не применять
- Ролик без проверяемых утверждений (музыка, влог): если после извлечения субтитров утверждений не нашлось — сообщить об этом и выдать только раздел «Реклама».
- Простой конспект без фактчека — использовать yt-konspekt.
- Текст/статья без видео, даже если просят «фактчек».

## Процедура
1. Извлечь субтитры (или автосубтитры), описание, закреплённый комментарий, метаданные через yt-dlp. Нет субтитров ни на одном языке → сообщить пользователю о невозможности извлечь текст и предложить прислать транскрипт.
2. Выписать проверяемые утверждения с таймкодом (факт, цифра, событие, цитата) и отдельно — мнения автора. При длительности >30 мин или >15 утверждений — отобрать топ-7 ключевых по сути ролика либо уточнить у пользователя нужный фрагмент.
3. Найти признаки рекламы в видео и описании: «спонсор», промокод, партнёрские/UTM-ссылки, интеграция без пометки.
4. По каждому утверждению выполнить отдельный веб-поисковый запрос и найти первоисточник (документ, оригинал исследования, пресс-релиз, данные ведомства, прямая цитата). Запрещено брать источник из памяти модели или из пересказа блогера/СМИ/ИИ без ссылки.
5. Вердикт: ПОДТВЕРЖДЕНО / ИСКАЖЕНО (контекст или цифры изменены) / ОПРОВЕРГНУТО / УСТАРЕЛО (было верно на дату публикации ролика, сейчас нет — указать дату) / НЕ НАЙДЕНО (источник не найден за разумное время, ≠ ложь) / МНЕНИЕ (вердикт не выносится, в графе «Источник» — прочерк).
6. Таблица: Таймкод | Утверждение | Вердикт | Источник | Комментарий.
7. Итог: счёт по вердиктам, отдельный раздел «Реклама» со списком вставок (обозначены ли автором), вывод о надёжности ролика.

## Жёсткие правила
1. Подтверждает только первоисточник; блогеры, форумы, ответы ИИ без ссылки — не источник.
2. Для каждого утверждения — обязательный отдельный веб-поиск, не полагаться на память модели.
3. Мнения не получают вердикт «подтверждено/опровергнуто» — только «мнение».
4. Источник не найден за разумное время → «НЕ НАЙДЕНО», источник не выдумывать.
5. Раздел «Реклама» обязателен всегда, даже если фактчек чист; всегда проверять описание и закреплённый комментарий — там чаще всего промокоды и рефссылки.
6. Не оценивать автора лично или политически — только вердикты по утверждениям и факты рекламы.
